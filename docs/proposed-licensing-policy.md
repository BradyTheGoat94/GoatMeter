# Proposed GoatMeter licensing policy — draft for owner review

This document records the owner's intended licensing model. It is not an adopted LICENSE, an executed commercial agreement, or a statement that all bundled materials are owned by the project. Have final enforceable license terms reviewed before publication.

## Owner's stated goal

People may use the GoatMeter application for free. The owner retains rights in the original project code to the extent those rights exist. A person or company wanting to take that code and sell a product based on it must obtain a separate paid commercial license from the owner.

## Proposed public application permission

Permit end users to download official GoatMeter releases and install and run the unmodified application without paying a license fee. Optional donations do not purchase code-reuse rights. Link-sharing to official downloads remains permitted.

The free application-use permission would not itself grant permission to copy project source into another product, distribute modified builds, sublicense project code, or sell the application or a derivative product. These uses require a separate written agreement, except where applicable law or third-party licenses independently grant rights. Whether unmodified binary redistribution and private source modifications should be permitted remains an explicit decision for the final license.

## Separate commercial code license

Anyone wanting commercial code-reuse rights must request permission and agree to written terms before distributing their product. The agreement should define the covered code/version, permitted uses, fee or royalty, attribution, update rights, redistribution rights, support obligations and termination terms. No price or royalty is set by this draft. Copying without permission is not automatically cured by later payment.

## Ownership and third-party boundaries

A license grants specified permissions; it does not transfer ownership of original project code. Do not claim exclusive ownership of third-party dependencies, game data, class icons, character artwork, or other external material. Their actual licenses and provenance must be audited and respected. Ownership/copyrightability of original work and contributor rights must be checked rather than assumed from a repository being public.

## Consequences for signing

This restrictive model is proprietary/freeware, not OSI open source. It does not satisfy the open-source-license condition of SignPath Foundation. Pause that application unless the owner changes this policy. Do not add MIT or GPL merely to obtain signing.

Trusted non-Store signing would require another eligible signing arrangement. Microsoft Store MSIX distribution is a separate potential route; app/driver compatibility and Store acceptance have not been verified. A self-signed certificate does not create public Windows trust.

## Publication decisions still needed

- Confirm the actual legal licensor and contributor rights.
- Confirm whether source remains public or becomes private; repository visibility is not changed by this draft.
- Review asset/dependency provenance.
- Decide unmodified binary redistribution and private modification permissions.
- Obtain legal review of final terms, then explicitly approve adding an operative LICENSE and installer acceptance text.

Until those decisions are resolved, this draft changes neither the public download nor existing rights.
